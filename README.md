# UTTOP Thesis Project

This repository contains demo videos and supporting material for my UTTOP thesis project on vision-based robotic control, including YOLO-based perception, camera calibration, simulation, and real-robot experiments.

## Current Demonstrations

- `Complete_CameraCalibration_done.mp4`  
  Camera calibration workflow demonstration.

- `MC_RTC_YOLO_Robot_Simulation.mp4`  
  YOLO-based perception integrated with MC_RTC in robot simulation.

- `MC_RTC_YOLO_Real_Robot.mp4`  
  Real robot demonstration using the MC_RTC and YOLO pipeline.

- `MC_RTC_YOLO_RealRobot_ContinuousMode.mp4`  
  Real robot demonstration in continuous operation mode.
